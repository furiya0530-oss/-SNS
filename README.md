# デイトレ銘柄スクリーニングツール（フェーズ1）

日足のCSVデータから、デイトレに向いた銘柄を絞り込むWebアプリです。
標準的なスクリーニング条件に加えて、**独自条件「レンジ回帰型ボラティリティ銘柄の検出」**を備えています。

---

## 1. これは何をするツールか

### 独自条件（このツールの主役）

> 日中の値動きは大きいのに、始値と終値はほとんど変わらない日が、何日も続いている銘柄

を探します。よく動くのに方向感が出ない銘柄は、まだ注目されていない可能性があり、
レンジ（一定の値幅）内で何度も売買チャンスが出やすい、という考え方に基づいています。

1日ごとに次の2つを計算します。

| 指標 | 計算式 | 意味 |
|---|---|---|
| 値幅率 | (高値 − 安値) ÷ 始値 | その日どれだけ動いたか（**大きいほど良い**） |
| 実体比率 | \|始値 − 終値\| ÷ 始値 | 始値と終値がどれだけ離れたか（**小さいほど良い**） |

**値幅率 ≧ 3% かつ 実体比率 ≦ 1%** の日を「該当日」と数え、
直近10日のうち該当日が60%以上ある銘柄を抽出します。
この「該当日の割合」がそのまま独自スコア（0〜1）になります。

※ 分母を2つとも始値に揃えているのは、「その日の中で完結する動き」を見たいためです。
   同じものさしで割ることで、値幅率と実体比率を同じ土俵で比較できます。

### 標準条件

| 条件 | 計算式 | 初期しきい値 |
|---|---|---|
| 売買代金 | 終値 × 出来高 | 10億円以上 |
| 出来高急増率 | 当日出来高 ÷ 過去5日平均出来高 | 2倍以上 |
| 日中値幅率 | (高値 − 安値) ÷ **前日終値** | 3%以上 |
| ギャップ率 | (始値 − 前日終値) ÷ 前日終値 | ±2%以上 |
| 移動平均 | 終値が5日移動平均を上抜け/下抜けした直後か | 上抜け or 下抜け |

しきい値はすべて画面のスライダーで変更でき、結果はその場で再計算されます。

## 2. 使い方

### インストール（最初の1回だけ）

```bash
pip install -r requirements.txt
```

### 起動

```bash
streamlit run app.py
```

自動でブラウザが開きます。開かない場合は、ターミナルに表示される
`http://localhost:8501` をブラウザのアドレス欄に貼り付けてください。

終了するときは、ターミナルで `Ctrl + C` を押します。

### 操作の流れ

1. 左のサイドバーで **「サンプルデータを使う」** を押す（または自分のCSVをアップロード）
2. 一覧表に、総合スコアの高い順で銘柄が並びます
3. サイドバーのスライダーを動かすと、結果がその場で更新されます
4. 下の「銘柄詳細」で銘柄を選ぶと、ローソク足チャートが表示されます
   - **紫の▼** = 独自条件の該当日
   - **薄紫の帯** = 判定対象になっている直近N日の範囲

## 3. CSVの形式

必須の列は次の8つです。列の順番は問いません。余分な列があっても無視されます。

| 列名 | 内容 | 例 |
|---|---|---|
| 銘柄コード | 証券コード | 1001 |
| 銘柄名 | 銘柄の名称 | レンジ機械 |
| 日付 | 対象日 | 2026-08-21 |
| 始値 | その日の最初の値段 | 2500.0 |
| 高値 | その日の最高値 | 2560.0 |
| 安値 | その日の最安値 | 2450.0 |
| 終値 | その日の最後の値段 | 2505.0 |
| 出来高 | 売買された株数 | 980000 |

- 1銘柄につき複数日分の行を並べてください（**最低でも判定日数N以上**）
- 25日移動平均まで表示したい場合は25日分以上あると確実です
- 文字コードは UTF-8 / Shift-JIS どちらでも自動判別します
- `"1,234"` のようなカンマ入りの数値も自動で変換します
- 日付や価格が読めない行は自動で除外し、画面に「◯行を除外しました」と表示します

## 4. ファイル構成

```
.
├── app.py                    画面（Streamlit）。計算はせず、表示だけを担当
├── data_loader.py            CSVの読み込み・検証・型変換。★将来ここをAPIに差し替える
├── screening.py              標準条件・独自条件の計算。このツールの計算エンジン
├── scoring.py                スコアの合算とランキング
├── sample_data/
│   ├── sample.csv            動作確認用の架空データ（8銘柄 × 40営業日）
│   └── generate_sample.py    サンプルCSVを作り直すスクリプト
└── requirements.txt
```

### 設計の考え方

「データを取ってくる係」と「計算する係」を分けています。

フェーズ2で kabuステーションAPI に切り替えるときは、`data_loader.py` の
`load_from_api()` を実装し、`load_from_csv()` と**同じ形の表**（上記8列）を返すようにするだけで済みます。
`screening.py` / `scoring.py` / `app.py` は変更不要です。

## 5. 動作確認

各ファイルは単体でも実行でき、計算結果を確認できます。

```bash
python data_loader.py   # CSVが読めるか
python screening.py     # 独自条件の判定結果
python scoring.py       # 総合ランキング
```

### サンプルデータの「答え」

`sample_data/sample.csv` は、判定結果が分かるように意図して作られています。
初期しきい値のまま実行すると、次の結果になれば正常です。

| コード | 銘柄名 | 独自スコア | 意図 |
|---|---|---:|---|
| 1001 | レンジ機械 | 1.00 | 値幅大・実体小が毎日続く（◎最上位） |
| 4001 | 低流動性テスト | 1.00 | 値動きは◎だが売買代金0.5億で標準条件は落ちる |
| 1002 | ボラ電子 | 0.80 | レンジ回帰型（やや弱い） |
| 1003 | きわどい商事 | 0.50 | 割合しきい値60%では落ちる（境界テスト） |
| 3002 | 出来高急増テック | 0.00 | 標準条件（出来高急増・ギャップ）だけ光る |
| 2001 | 上昇トレンド薬品 | 0.00 | **値幅は大きいが実体も大きい**ので該当しない |
| 2002 | 下落トレンド銀行 | 0.00 | 同上（下向き） |
| 3001 | 静かなインフラ | 0.00 | **実体は小さいが値幅が足りない**ので該当しない |

2001 と 3001 は、独自条件の「値幅が大きい **かつ** 実体が小さい」という
2つの条件が両方効いているかを確かめるための対照データです。
片方だけの銘柄がスコア0になっていれば、ロジックは正しく動いています。

### しきい値を動かしたときの確認

- 割合しきい値を **0.60 → 0.50** に下げる → 「きわどい商事」がクリアに変わる
- 実体比率しきい値を **0.010 → 0.025** に上げる → トレンド銘柄も該当し始める（＝条件が緩すぎる状態）
- 値幅率しきい値を **0.030 → 0.010** に下げる → 「静かなインフラ」が該当し始める
