# 英文法学び直しアプリ 要件定義書

2026-10-23

## 概要

TOEICを受ける社会人が、中学レベルの英文法をビジネス英語で学び直すスマホアプリ。setlogやBeRealのような「突然届く通知に短時間で応える」強制力で、毎日少しずつ続けさせる。

- コンセプト: 中学文法を、ビジネス英語で総復習
- 世界観: 会社員RPG。新入社員から始まり、文法ステージをクリアするごとに昇進する
- 前提: まずは自分用。一人で成立する設計にし、後から仲間機能を足せる構造にする

## 対象ユーザーと利用シーン

対象はTOEICのスコアを上げたいが、中学文法があやふやな社会人。子ども向け教材には抵抗がある層を想定する。

- 利用シーン: 通勤中、昼休み、夜のスキマ時間
- 1回の利用時間: 1問あたり60秒以内、1日合計で数分
- 初期ユーザー: 開発者本人

## 学習コンテンツ

中学文法を6つの役職ステージに分け、TOEIC Part 5で頻出の品詞問題と前置詞・接続詞の区別を追加する。例文はすべてオフィスの場面（メール、会議、出張など）にする。

| ステージ | 単元 |
| --- | --- |
| 1. 新入社員 | be動詞と一般動詞、名詞の単数・複数、代名詞（I / my / me / mine） |
| 2. 主任 | 時制（現在・過去・未来・進行形）、主語と動詞の一致、品詞の基本 |
| 3. 係長 | 助動詞、前置詞、接続詞、前置詞と接続詞の区別（during / while など）、品詞の見分け方 |
| 4. 課長 | 不定詞、動名詞、比較 |
| 5. 部長 | 受動態、現在完了 |
| 6. 役員 | 分詞、関係代名詞、仮定法 |

各単元には、上司キャラが話す短い解説文をつける。

## 出題形式と1問の流れ

基本はTOEIC Part 5と同じ4択の穴埋めとし、慣れてきたら並べ替えと間違い探しを混ぜる。

1. ランダムな時刻に出題通知が届く
2. 通知を開くと60秒のタイマー付きで1問が表示される
3. 回答直後に正誤と、上司キャラによる1〜2行の解説を表示する
4. 結果を当日の学習ログに記録する
5. 1日の終わりに「今日の文法ログ」として自動でまとめ、週末に「今週の成績表」を作る

## 強制力の仕組み

仲間の目がなくても続くよう、アプリ側に強制力を持たせる。

| 機能 | 内容 |
| --- | --- |
| ランダム出題通知 | 1日数回、設定した時間帯の中でランダムに通知。60秒を過ぎて回答すると「遅刻」マークがつく |
| 出題時間帯の設定 | 平日は通勤・昼休み・夜のみなど、会議中に通知が来ないよう自分で設定できる |
| 上司キャラ | 未回答なら催促し、正解すれば褒める。昇進・降格を告げる役も担う |
| 未処理タスク | 答えなかった問題は消えずに「未処理案件」として溜まる。一定数を超えると降格 |
| 出勤記録 | 毎日の回答を連続出勤日数として表示する |
| 全国一斉出題（フェーズ2） | 全ユーザーに同じ時刻・同じ問題を出し、回答後に全国正答率を表示する |

## 問題の用意方法

毎日の出題は事前に作った問題を使い、昇進試験だけAIで都度生成する。品質の安定とマンネリ防止を両立させるため。

**事前に作成するもの**

- 各単元の解説文（上司キャラのセリフ）
- 通知用の問題を単元ごとに約20問。AIで作成してよいが、正解が1つだけになっているかを自分で確認してから登録する

**都度生成するもの：昇進試験**

- 各ステージの最後に、そのステージの単元から約10問をAIが新しく作る
- 毎日の出題で間違えた単元を多めに出す
- 合格で昇進、不合格なら再受験

**AI生成のルール**

- 入力: 単元、難易度、ビジネス場面
- 出力: 問題文、選択肢、正解、解説をセットにしたJSON
- 2段階チェック: 生成後、別のAI呼び出しで「正解が1つだけか」を検証し、不合格の問題は作り直す

## 仲間機能への拡張

全国一斉出題の仕組みを先に作っておけば、グループ機能は集計範囲を絞るだけで追加できる。一人用と仲間用で仕組みを作り直さない。

- グループ内の正答率とランキング
- 自分が回答するまで仲間の結果が見えない仕組み
- サボるとグループ内に表示される

拡張に備え、ユーザーID・出題ID・回答時刻を最初からデータに持たせておく。

## 開発フェーズ

一人用を先に完成させ、3段階で広げる。

1. **フェーズ1（一人用）**: ランダム出題通知、60秒回答、解説表示、上司キャラ、未処理タスク、出勤記録、昇進試験のAI生成、学習ログ
2. **フェーズ2（全国一斉出題）**: 全ユーザー同時出題、全国正答率の表示
3. **フェーズ3（仲間機能）**: グループ作成、グループ内正答率とランキング

## 非機能要件・注意点

- 通知: アプリを閉じていても届くプッシュ通知が必須
- AI利用料: 自分用なら昇進試験の生成のみで少額に収まる想定。APIキーはアプリ内に直接書かず、サーバー側で管理する
- 問題の品質: 事前作成の問題は自分で確認、AI生成の問題は2段階チェックを通す
- 強制力の加減: 降格などのペナルティが強すぎると挫折につながるため、休日モードなど逃げ道を用意する
