# のぞきみ日記（長文限定・匿名の日記覗き見SNS）

長文投稿限定の匿名SNSアプリ。React + Vite で作った土台です。
今回作ったのは **発見画面** と **投稿画面** の2画面のみです。

- 仕様書：[`docs/diary-peek-sns-spec.md`](docs/diary-peek-sns-spec.md)
- ワイヤーフレーム：[`docs/diary-peek-sns-wireframe.html`](docs/diary-peek-sns-wireframe.html)

---

## 動かし方

はじめての人は、ターミナルでこのフォルダを開いて次の2つを順番に実行してください。

```bash
npm install   # 必要な部品をダウンロードする（最初の1回だけ）
npm run dev   # 開発用サーバーを起動する
```

表示された `http://localhost:5173/` をブラウザで開くとアプリが動きます。
止めたいときは、ターミナルで `Ctrl + C` を押してください。

| コマンド | 何をするか |
| --- | --- |
| `npm run dev` | 開発用サーバーを起動（保存すると画面が自動更新される） |
| `npm run build` | 公開用のファイルを `dist/` に書き出す |
| `npm run preview` | ビルドしたものを確認用に表示する |

## ファイル構成（どのファイルが何をしているか）

```
index.html            ブラウザが最初に読むファイル。フォントの読み込みもここ
src/
├── main.jsx          アプリの入口。App を画面に描画するだけ
├── App.jsx           ★中心。日記データを持ち、画面（タブ）を切り替える
├── styles.css        見た目（色・文字・レイアウト）を全部まとめたファイル
├── constants.js      「最低400字」「タグは5個まで」などの決まりごとの数字
├── data/
│   └── samplePosts.js  最初から入っているサンプル日記3件
├── utils/
│   └── time.js       「3時間前」のような日時表示を作る関数
├── components/       画面をまたいで使う小さな部品
│   ├── PhoneFrame.jsx  スマホ風の外枠（見た目だけ）
│   ├── TabBar.jsx      下のタブバー
│   └── DiaryCard.jsx   日記1件分のカード（いいねボタン・タグ・日時）
└── screens/          画面そのもの
    ├── DiscoverScreen.jsx  【画面1】発見
    └── PostScreen.jsx      【画面2】投稿
```

### データの流れ

日記データは **App.jsx が1か所でまとめて持っています**（`useState`）。

```
   [App.jsx]  posts（日記の配列）を持つ
      │
      ├─ posts と onToggleLike を渡す → [DiscoverScreen] → [DiaryCard]
      │                                                      ↑ いいねが押されたら
      │                                                        App に「押されたよ」と伝える
      │
      └─ onSubmit を渡す ───────────→ [PostScreen]
                                          ↑ 投稿ボタンが押されたら
                                            入力内容を App に渡す → posts に追加される
```

ポイントは「**データを持つのは App だけ**」という点です。
子のコンポーネントは受け取ったものを表示し、何か起きたら親に伝えるだけ。
こうしておくと、画面が増えても混乱しにくくなります。

## 今できること

### 1. 発見画面

- 匿名の日記がカード形式で一覧表示される
- カードには 匿名ペルソナ番号 / 投稿日時（◯時間前）/ 本文 / ハッシュタグ / いいねボタン
- いいねを押すと数が増え、もう一度押すと戻る（見た目だけ・保存はされません）
- 長文は5行で折りたたみ、「続きを読む」で全文表示
- 上部に「今週のお題」バナー（表示のみ）

### 2. 投稿画面

- 長文用のテキストエリア
- 文字数カウンター + 進捗バー。**400字未満は投稿ボタンが押せません**
- ハッシュタグは**最大5個**まで。Enter または「＋ 追加」で追加、`×` で削除
  - 先頭の `#` は自動で取り除き、重複したタグは追加されません
- 投稿すると発見画面へ移動し、一覧の一番上に自分の日記が追加されます

## つまずいたときは

| 症状 | 対処 |
| --- | --- |
| `npm: command not found` | Node.js（v18以上）をインストールしてください |
| 画面が真っ白 | ターミナルの赤いエラー文を確認。ブラウザの検証ツール（F12）のConsoleも見る |
| フォントが違って見える | Klee One はネット経由で読み込むため、オフラインだと別の書体になります |
| 投稿が消えた | 今は保存の仕組みがないため、再読み込みで消えます（仕様どおりです） |
