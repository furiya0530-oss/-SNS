# デイトレ銘柄スクリーニングツール（フェーズ1）

日足のCSVデータから、デイトレに向いた銘柄を絞り込むWebアプリです。
標準的なスクリーニング条件に加えて、**独自条件「レンジ回帰型ボラティリティ銘柄の検出」**を備えています。

---

## 1. これは何をするツールか

### 独自条件（このツールの主役）

> 日中の値動きは大きいのに、始値と終値はほとんど変わらない日が、何日も続いている銘柄

を探します。よく動くのに方向感が出ない銘柄は、まだ注目されていない可能性があり、
レンジ（一定の値幅）内で何度も売買チャンスが出やすい、という考え方に基づいています。

1日ごとに次の2つを計算します。

| 指標 | 計算式 | 意味 |
|---|---|---|
| 値幅率 | (高値 − 安値) ÷ 始値 | その日どれだけ動いたか（**大きいほど良い**） |
| 実体比率 | \|始値 − 終値\| ÷ 始値 | 始値と終値がどれだけ離れたか（**小さいほど良い**） |

**値幅率 ≧ 3% かつ 実体比率 ≦ 1%** の日を「該当日」と数え、
直近10日のうち該当日が60%以上ある銘柄を抽出します。

※ 分母を2つとも始値に揃えているのは、「その日の中で完結する動き」を見たいためです。
   同じものさしで割ることで、値幅率と実体比率を同じ土俵で比較できます。

#### 該当日の数え方は2通り（画面で切替）

| 方式 | 内容 |
|---|---|
| **直近重視**（初期値） | 直近の日ほど重く数える。10日なら古い日を1、最新日を10として重み付け |
| 単純割合 | 該当日数 ÷ 判定日数（要件定義書どおりの計算） |

単純割合だと「並び順」の情報が捨てられ、
`●●●●●・・・・・`（状態がもう終わった）と `・・・・・●●●●●`（今まさに続いている）が
どちらも 0.50 になってしまいます。デイトレで狙いたいのは後者なので、直近重視を初期値にしています。

一覧には「連続」列（最新日から何日連続で該当しているか）もあわせて表示します。

#### 終値レンジ幅の条件

1日ごとの形だけを見ていると、**毎日きれいに行って来いなのに、日をまたぐギャップで
少しずつ切り上がっていく“階段状のトレンド銘柄”**も満点になってしまいます。
そこで期間全体の値動きの幅も確認します。

```
終値レンジ幅 = (直近N日の最高終値 − 最安終値) ÷ 平均終値      初期値：10%以内
```

これを超えた銘柄は独自スコアを0にし、一覧の「除外理由」列にその旨を表示します。
（サンプルの「階段上昇テスト」がこのケースです。この条件を切ると1位に浮上します）

### 標準条件

| 条件 | 計算式 | 初期しきい値 |
|---|---|---|
| 売買代金 | 終値 × 出来高 | 10億円以上（**足切り**） |
| 出来高急増率 | 当日出来高 ÷ 過去5日平均出来高 | 2倍以上 |
| 日中値幅率 | (高値 − 安値) ÷ **前日終値** | 3%以上 |
| ギャップ率 | (始値 − 前日終値) ÷ 前日終値 | ±2%以上 |
| 移動平均 | 終値が5日移動平均を上抜け/下抜けした直後か | 上抜け or 下抜け |

売買代金だけは減点ではなく**足切り**（一覧から除外）にしています。
減点だと、実際には売買が成立しにくい小型銘柄が上位に残り続けてしまうためです。
除外した銘柄は画面上の「除外した銘柄」から中身を確認でき、チェックを外せば一覧に戻せます。

しきい値はすべて画面のスライダーで変更でき、結果はその場で再計算されます。

## 2. 使い方

### インストール（最初の1回だけ）

```bash
pip install -r requirements.txt
```

### 起動

```bash
streamlit run app.py
```

自動でブラウザが開きます。開かない場合は、ターミナルに表示される
`http://localhost:8501` をブラウザのアドレス欄に貼り付けてください。

終了するときは、ターミナルで `Ctrl + C` を押します。

### 操作の流れ

1. 左のサイドバーで **「サンプルデータを使う」** を押す（または自分のCSVをアップロード）
2. 一覧表に、総合スコアの高い順で銘柄が並びます
3. サイドバーのスライダーを動かすと、結果がその場で更新されます
4. 下の「銘柄詳細」で銘柄を選ぶと、ローソク足チャートが表示されます
   - **紫の▼** = 独自条件の該当日
   - **薄紫の帯** = 判定対象になっている直近N日の範囲

## 3. CSVの形式

必須の列は次の8つです。列の順番は問いません。余分な列があっても無視されます。

| 列名 | 内容 | 例 |
|---|---|---|
| 銘柄コード | 証券コード | 1001 |
| 銘柄名 | 銘柄の名称 | レンジ機械 |
| 日付 | 対象日 | 2026-08-21 |
| 始値 | その日の最初の値段 | 2500.0 |
| 高値 | その日の最高値 | 2560.0 |
| 安値 | その日の最安値 | 2450.0 |
| 終値 | その日の最後の値段 | 2505.0 |
| 出来高 | 売買された株数 | 980000 |

- 1銘柄につき複数日分の行を並べてください（**最低でも判定日数N以上**）
- 25日移動平均まで表示したい場合は25日分以上あると確実です
- 文字コードは UTF-8 / Shift-JIS どちらでも自動判別します
- `"1,234"` のようなカンマ入りの数値も自動で変換します
- 日付や価格が読めない行は自動で除外し、画面に「◯行を除外しました」と表示します

## 4. ファイル構成

```
.
├── app.py                    画面（Streamlit）。計算はせず、表示だけを担当
├── data_loader.py            CSVの読み込み・検証・型変換。★将来ここをAPIに差し替える
├── screening.py              標準条件・独自条件の計算。このツールの計算エンジン
├── scoring.py                スコアの合算とランキング
├── sample_data/
│   ├── sample.csv            動作確認用の架空データ（8銘柄 × 40営業日）
│   └── generate_sample.py    サンプルCSVを作り直すスクリプト
└── requirements.txt
```

### 設計の考え方

「データを取ってくる係」と「計算する係」を分けています。

フェーズ2で kabuステーションAPI に切り替えるときは、`data_loader.py` の
`load_from_api()` を実装し、`load_from_csv()` と**同じ形の表**（上記8列）を返すようにするだけで済みます。
`screening.py` / `scoring.py` / `app.py` は変更不要です。

## 5. 動作確認

各ファイルは単体でも実行でき、計算結果を確認できます。

```bash
python data_loader.py   # CSVが読めるか
python screening.py     # 独自条件の判定結果
python scoring.py       # 総合ランキング
```

### サンプルデータの「答え」

`sample_data/sample.csv` は、判定結果が分かるように意図して作られています。
初期しきい値のまま実行すると、次の結果になれば正常です。

| 順位 | コード | 銘柄名 | 独自スコア | 意図 |
|---:|---|---|---:|---|
| 1 | 1001 | レンジ機械 | 1.00 | 値幅大・実体小が毎日続く（◎最上位） |
| 2 | 1002 | ボラ電子 | 0.87 | レンジ回帰型。直近4日連続なので直近重視だと0.80→0.87に上がる |
| 3 | 1003 | きわどい商事 | 0.45 | 該当が1日おき。最新日が非該当なので0.50→0.45に下がる |
| 4 | 3002 | 出来高急増テック | 0.00 | 標準条件（出来高急増・ギャップ）だけ光る |
| 5 | 5001 | 階段上昇テスト | 0.00 | **該当率100%なのにレンジ幅14.8%**。トレンドなので除外 |
| 6 | 2001 | 上昇トレンド薬品 | 0.00 | **値幅は大きいが実体も大きい**ので該当しない |
| 7 | 2002 | 下落トレンド銀行 | 0.00 | 同上（下向き） |
| 8 | 3001 | 静かなインフラ | 0.00 | **実体は小さいが値幅が足りない**ので該当しない |
| 除外 | 4001 | 低流動性テスト | 1.00 | 値動きは◎だが売買代金0.5億円なので足切り |

この3銘柄が、ロジックが正しく動いているかを確かめる要になります。

- **2001**（値幅だけ大きい）と **3001**（実体だけ小さい）がどちらも0点
  → 「値幅が大きい **かつ** 実体が小さい」の *かつ* が効いている
- **5001**（毎日は行って来いだが階段状に上昇）が0点
  → 終値レンジ幅の条件が効いている
- **4001**（値動きは満点だが売買代金0.5億円）が一覧から消える
  → 流動性の足切りが効いている

### しきい値を動かしたときの確認

- 割合しきい値を **0.60 → 0.45** に下げる → 「きわどい商事」がクリアに変わる
- 実体比率しきい値を **0.010 → 0.025** に上げる → トレンド銘柄も該当し始める（＝条件が緩すぎる状態）
- 値幅率しきい値を **0.030 → 0.010** に下げる → 「静かなインフラ」が該当し始める
- **終値レンジ幅の条件を切る** → 「階段上昇テスト」が1位に浮上する（この条件が効いている証拠）
- **売買代金の足切りを切る** → 「低流動性テスト」が上位に戻ってくる
- **スコアの数え方を「単純割合」にする** → ボラ電子 0.87→0.80、きわどい商事 0.45→0.50 に戻る
