# のぞきみ日記（長文限定・匿名の日記覗き見SNS）

長文投稿限定の匿名SNSアプリ。React + Vite で作った土台です。
5つのタブ（発見・追いかけ中・投稿・通知・マイページ）すべてに画面があります。

- 仕様書：[`docs/diary-peek-sns-spec.md`](docs/diary-peek-sns-spec.md)
- ワイヤーフレーム：[`docs/diary-peek-sns-wireframe.html`](docs/diary-peek-sns-wireframe.html)

---

## 動かし方

はじめての人は、ターミナルでこのフォルダを開いて次の2つを順番に実行してください。

```bash
npm install   # 必要な部品をダウンロードする（最初の1回だけ）
npm run dev   # 開発用サーバーを起動する
```

表示された `http://localhost:5173/` をブラウザで開くとアプリが動きます。
止めたいときは、ターミナルで `Ctrl + C` を押してください。

| コマンド | 何をするか |
| --- | --- |
| `npm run dev` | 開発用サーバーを起動（保存すると画面が自動更新される） |
| `npm run build` | 公開用のファイルを `dist/` に書き出す |
| `npm run preview` | ビルドしたものを確認用に表示する |

## ファイル構成（どのファイルが何をしているか）

```
index.html            ブラウザが最初に読むファイル。フォントの読み込みもここ
src/
├── main.jsx          アプリの入口。App を画面に描画するだけ
├── App.jsx           ★中心。日記データを持ち、画面（タブ）を切り替える
├── styles.css        見た目（色・文字・レイアウト）を全部まとめたファイル
├── constants.js      「最低400字」「タグは5個まで」などの決まりごとの数字
├── data/              画面確認用の固定データ（サンプル）
│   ├── samplePosts.js         発見画面に最初から並ぶ日記3件
│   ├── sampleFollowing.js     追いかけ中画面の一覧
│   └── sampleNotifications.js 通知画面の一覧
├── utils/
│   ├── time.js        「3時間前」のような日時表示を作る関数
│   └── storage.js      投稿データを localStorage に保存・読み込みする関数
├── components/       画面をまたいで使う小さな部品
│   ├── PhoneFrame.jsx  スマホ風の外枠（見た目だけ）
│   ├── TabBar.jsx      下のタブバー
│   └── DiaryCard.jsx   日記1件分のカード（いいねボタン・タグ・日時）
└── screens/          画面そのもの
    ├── DiscoverScreen.jsx     【画面1】発見
    ├── FollowingScreen.jsx    【画面2】追いかけ中
    ├── PostScreen.jsx         【画面3】投稿
    ├── NotificationScreen.jsx 【画面4】通知
    └── MyPageScreen.jsx       【画面5】マイページ
```

### データの流れ

日記データは **App.jsx が1か所でまとめて持っています**（`useState`）。

```
   [App.jsx]  posts（日記の配列）を持つ ── localStorage に自動保存
      │
      ├─ posts と onToggleLike を渡す → [DiscoverScreen] → [DiaryCard]
      │                                                      ↑ いいねが押されたら
      │                                                        App に「押されたよ」と伝える
      │
      ├─ onSubmit を渡す ───────────→ [PostScreen]
      │                                   ↑ 投稿ボタンが押されたら
      │                                     入力内容を App に渡す → posts に追加される
      │
      └─ myPostCount（自分の投稿数）を渡す → [MyPageScreen]
```

ポイントは「**データを持つのは App だけ**」という点です。
子のコンポーネントは受け取ったものを表示し、何か起きたら親に伝えるだけ。
こうしておくと、画面が増えても混乱しにくくなります。

追いかけ中・通知の2画面は、まだログイン機能が無いので
`src/data/` の固定データ（サンプル）をそのまま表示しているだけです。
発見・投稿・マイページの3画面だけが、実際の `posts` state と連動しています。

## 今できること

### 1. 発見画面

- 匿名の日記がカード形式で一覧表示される
- カードには 匿名ペルソナ番号 / 投稿日時（◯時間前）/ 本文 / ハッシュタグ / いいねボタン
- いいねを押すと数が増え、もう一度押すと戻る
- 長文は5行で折りたたみ、「続きを読む」で全文表示
- 上部に「今週のお題」バナー（表示のみ）

### 2. 追いかけ中画面

- フォロー中の相手を「新着あり」「今週は更新なし」に分けて一覧表示（サンプルデータ）

### 3. 投稿画面

- 長文用のテキストエリア
- 文字数カウンター + 進捗バー。**400字未満は投稿ボタンが押せません**
- ハッシュタグは**最大5個**まで。Enter または「＋ 追加」で追加、`×` で削除
  - 先頭の `#` は自動で取り除き、重複したタグは追加されません
- 投稿すると発見画面へ移動し、一覧の一番上に自分の日記が追加されます

### 4. 通知画面

- いいね・フォロー・コメントの通知を一覧表示（サンプルデータ）

### 5. マイページ

- 自分のペルソナ情報と、実際の投稿数（累計何本投稿したか）
- コメント権ステータス（仕様書どおり「累計5本投稿」で獲得、というルールに沿った進捗バー）
- 設定メニュー一覧（見た目のみ。押しても画面遷移はしません）

### データの保存について

投稿（日記といいね状態）は **ブラウザの localStorage に保存**されます。
ページを閉じたり再読み込みしても消えません。ただし、あくまで
「今使っているブラウザ・この端末だけ」に保存される簡易的な仕組みなので、
別の端末やブラウザからは見えません（サーバーに保存するデータベースは
まだ実装していません）。

## 今回まだ作っていないもの

土台なので、次のものはあえて入れていません。

- ログイン / 会員登録（投稿者は仮のペルソナ `#0847` 固定）
- サーバー側のデータベース保存（あくまでブラウザの localStorage のみ）
- 追いかけ中・通知の一覧は固定のサンプルデータ（実際にフォロー/通知が届く仕組みではない）
- コメント機能、スタンプ、通報機能、お題での絞り込み
- 日記詳細画面（カードをタップしての全文・コメント表示）

### 次に手を付けるなら

1. **日記詳細画面** … カードを押すと全文とコメントが見られるようにする
2. **追いかける機能** … 発見画面に「追いかける」ボタンを付け、押した相手が
   追いかけ中画面に実際に反映されるようにする
3. **バックエンド連携** … localStorage をやめて、本物のサーバー・データベースに保存する

## つまずいたときは

| 症状 | 対処 |
| --- | --- |
| `npm: command not found` | Node.js（v18以上）をインストールしてください |
| 画面が真っ白 | ターミナルの赤いエラー文を確認。ブラウザの検証ツール（F12）のConsoleも見る |
| フォントが違って見える | Klee One はネット経由で読み込むため、オフラインだと別の書体になります |
| 投稿した日記が急に消えた | ブラウザの「閲覧履歴・データを削除」をすると localStorage も消えます |
| 別の端末で見たら投稿が無い | localStorage は端末・ブラウザごとに別々に保存されるため、仕様どおりです |
