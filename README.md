# 🚀 100個アプリ制作チャレンジ管理アプリ

「100個アプリを作る」チャレンジの **アイデア管理・進捗管理・振り返り** をまとめてできる Web アプリです。
データはブラウザの中（localStorage）に保存されるので、**サーバーもログインも不要**で使えます。

## 画面構成

| 画面 | できること |
|---|---|
| 📊 ダッシュボード | 達成率・完了数・グラフ・連続活動日数・直近の活動履歴 |
| 🗂 一覧 | 100個の枠をステータス別に色分け表示／検索・絞り込み |
| 📝 詳細・編集 | 1アプリ分の情報を登録・編集（一覧のマスをクリック） |
| 🏆 振り返り | 完成アプリのポートフォリオ＋全体の学びメモ |

## 動かし方（3ステップ）

### 1. 必要なものを準備する

**Node.js**（JavaScript を動かすための土台）が必要です。
[https://nodejs.org/](https://nodejs.org/) から LTS 版をインストールしてください。

インストールできたか確認：

```bash
node -v   # v20.0.0 のようにバージョンが出ればOK
```

### 2. ライブラリをインストールする

このフォルダをターミナル（コマンドを打つ画面）で開いて、次を実行します。

```bash
npm install
```

> 📦 `npm install` は「このアプリが使う部品（React や Tailwind）をまとめてダウンロードする」コマンドです。
> 初回だけ少し時間がかかります。`node_modules` というフォルダができれば成功です。

### 3. 開発サーバーを起動する

```bash
npm run dev
```

ターミナルに次のような表示が出ます。

```
➜  Local:   http://localhost:5173/
```

この **http://localhost:5173/** をブラウザで開くと、アプリが表示されます。
（ターミナルで `Ctrl + C` を押すと停止します）

> 💡 **開発サーバー**とは、作業中のアプリを自分のパソコンの中だけで表示してくれる仕組みです。
> ファイルを保存すると、ブラウザが自動で更新されます。

### （おまけ）本番用に書き出す

```bash
npm run build     # dist フォルダに公開用ファイルが作られる
npm run preview   # 書き出した結果を確認する
```

`dist` フォルダの中身を Netlify や Vercel、GitHub Pages にアップすれば公開できます。

## 使い方

1. **一覧画面**でマス（No.1〜No.100）をクリック
2. アプリ名・概要・カテゴリ・難易度・ステータスなどを入力
3. **「保存する」**を押す → ブラウザに自動保存されます
4. **ダッシュボード**で達成率やグラフを確認

### ステータスと色

| ステータス | 色 | 意味 |
|---|---|---|
| 未着手 | グレー | まだ何も決まっていない |
| アイデアのみ | 黄色 | 作りたいものが決まった |
| 進行中 | 青 | 制作中 |
| 完成 | 緑 | できあがった 🎉 |
| 中断 | 紫 | 一旦ストップ中 |

> ステータスを「進行中」にすると着手日が、「完成」にすると完成日が、
> 空の場合に自動で今日の日付に入ります。

### ⚠ データについての注意

記録は **このブラウザの中だけ** に保存されます。以下の場合は消えるので注意してください。

- ブラウザの閲覧データ（キャッシュ・サイトデータ）を削除した
- シークレット／プライベートモードで使っている
- 別の端末・別のブラウザで開いた

大切な記録は画面下の **「⬇ バックアップ保存」** で JSON ファイルとして保存しておきましょう。
戻すときは **「⬆ バックアップ読込」** から同じファイルを選びます。

## ファイル構成（改造するときの地図）

```
src/
├── main.jsx              アプリの起動ファイル（触ることはほぼ無い）
├── App.jsx               画面の切り替え＋ヘッダー／フッター
├── index.css             Tailwind の読み込みと基本スタイル
│
├── data/                 【データの定義まわり】
│   ├── constants.js      ステータスの種類・色・カテゴリ候補 ← 色を変えたいならここ
│   ├── model.js          1アプリ分のデータ項目の定義 ← 項目を増やすならここ
│   └── storage.js        localStorage への保存・読み込み
│
├── hooks/
│   └── useAppData.js     データの読み込み・更新・自動保存をまとめた本体
│
├── utils/                【計算・変換の部品】
│   ├── date.js           日付の変換・比較
│   └── stats.js          集計（達成率・グラフ用データ・ストリーク）
│
├── components/           【小さな画面部品】
│   ├── AppCell.jsx       一覧の1マス
│   ├── Card.jsx          白い枠
│   ├── ChartTooltip.jsx  グラフの吹き出し
│   ├── ProgressBar.jsx   進捗バー
│   ├── StatusBadge.jsx   ステータスのラベル
│   └── TagInput.jsx      使用技術のタグ入力欄
│
└── pages/                【4つの画面】
    ├── Dashboard.jsx
    ├── ListPage.jsx
    ├── DetailPage.jsx
    └── ReviewPage.jsx
```

## 改造のヒント

| やりたいこと | 直すファイル |
|---|---|
| ステータスの色や名前を変える | `src/data/constants.js` の `STATUSES` |
| カテゴリの候補を増やす | `src/data/constants.js` の `CATEGORY_SUGGESTIONS` |
| 100個 → 50個 に変える | `src/data/constants.js` の `TOTAL_APPS` |
| 入力項目を追加する | `src/data/model.js` に項目追加 → `src/pages/DetailPage.jsx` に入力欄追加 |
| グラフを増やす | `src/utils/stats.js` に集計関数を追加 → `src/pages/Dashboard.jsx` で表示 |

## よくあるエラー

| エラー表示 | 意味と直し方 |
|---|---|
| `command not found: npm` | Node.js が未インストール。[nodejs.org](https://nodejs.org/) から入れる |
| `Cannot find module 'xxx'` | 部品が足りない。`npm install` をもう一度実行する |
| `Port 5173 is in use` | そのポートを別のアプリが使用中。`npm run dev -- --port 3000` のように番号を変える |
| 画面が真っ白 | ブラウザで `F12` → Console タブに赤いエラーが出ていないか確認する |

## 技術スタック

- [React](https://react.dev/) 19 — 画面を作るライブラリ
- [Vite](https://vite.dev/) — 開発サーバー＆ビルドツール
- [Tailwind CSS](https://tailwindcss.com/) v4 — クラス名でデザインする CSS
- [recharts](https://recharts.org/) — グラフ描画
- localStorage — データ保存（サーバー不要）
